# ProgrammingObsidian

Репозиторій із персональною базою знань про програмування в Obsidian. Тут зберігаються нотатки за джерелами, узагальнені концепти, карти тем, практичні playbook-и та сирі capture-нотатки.

## Структура

- `vault/` - основний простір нотаток
- `vault/01-Sources/` - нотатки, прив'язані до конкретних джерел
- `vault/02-Concepts/` - узагальнені ідеї та концепти
- `vault/03-Maps/` - тематичні карти й навігаційні нотатки
- `vault/04-Playbooks/` - практичні інструкції та підходи
- `vault/05-Inbox/` - сирі нотатки, які ще не розкладені по структурі

## Типи нотаток

- `Sources` - конспекти книг, статей, документації та курсів
- `Concepts` - ідеї, що мають цінність поза межами одного джерела
- `Maps` - нотатки для огляду теми та зв'язування пов'язаних матеріалів
- `Playbooks` - покрокові підходи, практики й робочі сценарії
- `Inbox` - тимчасові capture-нотатки для подальшого опрацювання

## Підтипи нотаток у Sources

У кожного джерела є головна source note і набір внутрішніх нотаток. Структура залежить від типу джерела.

### Книги

Кожна книга в `vault/01-Sources/books/` зазвичай містить:

- `Source note` - головну нотатку про книгу
- `Inbox` - сирі виписки та проміжні capture-нотатки
- `Chapters` - нотатки за окремими розділами
- `Concepts` - ідеї, винесені з книги, але ще прив'язані до неї
- `Code` - приклади коду та технічні фрагменти з джерела

### Статті, документація та курси

Джерела в `vault/01-Sources/articles/`, `vault/01-Sources/docs/` і `vault/01-Sources/courses/` зазвичай містять:

- `Source note` - головну нотатку про джерело
- `Inbox` - сирі виписки та швидкі capture-нотатки
- `Notes` - основні нотатки за секціями, лекціями або частинами матеріалу
- `Concepts` - ідеї, винесені з конкретного джерела
- `Code` - приклади коду, API-використання або технічні фрагменти
