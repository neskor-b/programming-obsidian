# ProgrammingObsidian

Репозиторій із персональною базою знань про програмування в Obsidian. Тут зберігаються нотатки за джерелами, узагальнені концепти, карти тем, практичні playbook-и та сирі capture-нотатки.

## Структура

- `vault/` - основний простір нотаток
- `vault/01-Sources/` - нотатки, прив'язані до конкретних джерел
- `vault/02-Concepts/` - узагальнені ідеї та концепти
- `vault/03-Maps/` - тематичні карти й навігаційні нотатки
- `vault/04-Playbooks/` - практичні інструкції та підходи
- `vault/05-Inbox/` - сирі нотатки, які ще не розкладені по структурі

## Типи нотаток

- `Sources` - конспекти книг, статей, документації та курсів
- `Concepts` - ідеї, що мають цінність поза межами одного джерела
- `Maps` - нотатки для огляду теми та зв'язування пов'язаних матеріалів
- `Playbooks` - покрокові підходи, практики й робочі сценарії
- `Inbox` - тимчасові capture-нотатки для подальшого опрацювання
